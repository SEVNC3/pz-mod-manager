Two fixes for 1.1.0.

- **Mods stay on after starting the game.** Build 42 empties its mod list the first time it starts after some game updates, unless a marker file is in `Zomboid/mods`. PZMM now writes that marker before you play, and it no longer copies a list the game emptied that way back into your profile. If your mods were switched off, restore your profile's snapshot from before you launched.
- **Updates install over the copy you run.** Updates could land in PZMM's default folder instead of the one you installed to, so your shortcuts kept opening the old version. Updates after this one install where PZMM is running from.
