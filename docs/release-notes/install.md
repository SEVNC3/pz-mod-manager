## How to install

**Windows:** download `PZMM_{VERSION}_x64-setup.exe` below and run it. Windows will probably say it protected your PC, because the installer isn't code-signed yet. Click **More info**, then **Run anyway**.

**Linux:** `PZMM_{VERSION}_amd64.AppImage` runs on any distro (`chmod +x` it first). On Debian or Ubuntu you can install `PZMM_{VERSION}_amd64.deb` instead with `sudo apt install ./PZMM_{VERSION}_amd64.deb`. Workshop downloads need `lib32gcc-s1`.

**A server with no desktop:** `pzmm-linux-x64` or `pzmm-windows-x64.exe` is the command-line version, one file.

**Already got PZMM?** It updates itself: click **Update and restart** above the tabs.

You don't need the `.sig` files or `latest.json`; they're for the updater. `SHA256SUMS.txt` lets you check your download.
