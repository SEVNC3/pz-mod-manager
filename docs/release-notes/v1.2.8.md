A small one, from your feedback on Discord and the Workshop page.

- **No more "invalid peer certificate" errors behind antivirus, a VPN or a company network.** PZMM now trusts the same certificates your computer does, so tools that check HTTPS traffic with a certificate of their own no longer block downloads, the Workshop or the server list. If something still blocks it, PZMM says so plainly and tells you what to change.

- **Find the broken mod keeps mods that need each other together.** It now tests groups of mods that need each other (like Project Viewpoint and its add-ons, or a car framework and its cars) instead of splitting them, so a mod is never on without what it needs and the search can't blame the wrong mod. When it narrows down to one group, it tells you that group. If the problem only happens with two mods from different groups together, it says so instead of blaming one.
- **Workshop pictures that don't load say so.** Previews and screenshots show a placeholder while they load, try once more if they fail, and then say "Image failed to load" instead of leaving a blank space. If that happens to you, Settings > About > Copy diagnostics and the log help us find out why.
