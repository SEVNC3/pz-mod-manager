- **What's new puts updates you can read first.** Mods whose updates have change notes or a changelog fill the scraps of paper and the top of the history. Updates with nothing to read go to the bottom, under No change notes. Same in the app and in game.
- **Two rows of notes in game.** The in-game What's new board keeps to two rows of scraps; the rest are in the history below.
- **We're sorry, in game.** Without the app, the in-game What's new tab explains why it's empty, with links to download PZMM and join the Discord.
- **PZMM in the main menu.** A box at the top right of the main menu opens into the latest patch notes, with a red ! when there's a new patch.
- **The game can ask PZMM for things.** From the in-game mod manager, ask PZMM to install a mod's missing requirements, back up a save, run Check setup, or open Browse Workshop or Make a mod. PZMM comes to the front on the right page, or starts if it isn't running (your browser asks to open it), and asks you first before installing or backing up.
- **Sort your profile from the game.** Dragging a mod between sections, or adding, renaming or removing a section, in the in-game mod manager does the same in your PZMM profile.
- **The game and PZMM keep in step.** PZMM tells the game it's running and which profile is on, confirms each change made in game, and ignores a game request over a minute old instead of jumping to the front. Renaming your profile, and arranging maps in the game, reach the other side too, and while PZMM is in front it picks up changes to the game's mod list at once. Sections you made in game before installing PZMM become your profile's.
- **PZMM warns when the game uses another Zomboid folder,** since the game then doesn't see PZMM's changes.
- **PZMM notices when the game didn't load your profile.** When the game's main menu reports a different mod list than the profile you're on, PZMM says so in the activity log.
- **Switch profiles from the game.** The in-game mod manager lists your PZMM profiles; pick one and PZMM switches once you say yes.
- **Check setup in game.** Check setup's problems show in the game's Problems, worded as in the app, with the same fix buttons. Safe fixes run at once; PZMM asks before the rest.
- **Save backups in game.** The game lists each save's PZMM backups and can restore one from the main menu, after PZMM asks. The save as it is now is backed up first.
- **What's new and settings, shared.** Reading What's new in the app or in game clears the badge in both, and a game started without PZMM still counts as played. The in-game manager's options (logo, watermark, patch notes box, tooltips) are in the app's Settings > Appearance too.
