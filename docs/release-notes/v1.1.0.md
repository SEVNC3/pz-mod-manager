A big release: a smarter load order, a full Workshop browser, safer installs and a new look.

## Load order

- **Your library and the load order are separate**, like Mod Organizer 2. Organise the left list however you like; the load order lives in its own list beside it, and dragging one never moves the other. Existing profiles keep their order.
- **Autosort** puts frameworks first and translations last and satisfies every `require`, `loadModAfter` and `loadModBefore` rule. Ctrl+Z undoes it.
- **Group by category** sorts your library into sections from the mods' Workshop tags. It asks before replacing sections of your own.
- Turning a mod on places it after the mods it needs.
- A map order list for dedicated servers, with **Autosort maps**.
- Drag a separator to move its whole section. The drop line shows exactly where it lands.
- Removing a separator leaves its mods where they were, as cards of their own.
- Select several mods with Ctrl/Shift+click, then enable, disable, move or remove them together.
- Undo and redo (Ctrl+Z / Ctrl+Y) for every list edit.
- Sort by load order, name, size, last change or problems.
- B41-only and B42-only badges.

## Workshop browser

- Everything Steam's own Workshop offers without logging in:
  - require or exclude any tag
  - popular over any period, from today to a year
  - search titles or descriptions
  - posted and updated filters
  - incompatible items only
- A Home view: popular this week, most subscribed, newest, recently updated and most required.
- An item panel with:
  - screenshots and videos
  - the full description, change notes and comments
  - required items, the mods that need it, the collections it's in, and more by the same author
- Collections, with **Install all**.
- Workshop pages open in the Steam client when it's running.

## Profiles, Project Viewpoint and servers

- One profile menu, grouped by game. Picking a profile from the other game switches to Project Viewpoint or back, and sets up ZombieBuddy when needed.
- Start a dedicated server from PZMM.
- `pzmm watch` checks a server's Workshop items and can run your restart script when they update.
- Share a profile as a code. A friend pastes it into **Import**, and PZMM installs the Workshop mods they're missing.

## Settings

- A full Settings tab: every folder PZMM uses, with Browse, Detect and checks for OneDrive, write access and disk space; move PZMM's data to another drive.
- Mod update checks on start or every few hours, then notify or install.
- Removed mods go to the Recycle Bin; optionally remove requirements nothing else uses; a size cap for backups.
- Extra game arguments, compact rows, mod IDs beside names, a remembered window, and **Copy diagnostics** for bug reports.
- A GitHub token, kept in Windows' credential store.

## Safer

- Changes made in the game's own mod menu are never saved over.
- Files PZMM can't read (a server `.ini`, a profile, `default.txt`) are left alone instead of being rewritten from scratch.
- Updating a mod while the game has it open fails cleanly instead of half-deleting it.
- Installing turns on only what's needed and compatible.
- A failed download is no longer reported as a success.
- Subscribing in Steam to a mod PZMM installed hands it over to Steam's copy, so it stays up to date.
- Importing a server or save's mods again updates its profile instead of replacing your sections.
- Server names can't carry shell commands.
- Writes are atomic and synced.
- The window no longer freezes on row clicks.

## Finding problems

- **Check setup** checks your profile and server configs.
- Lua errors from the last game session are counted per mod.
- **Find the broken mod** narrows down a crash by halving your mods each time you test.
- PZMM warns when your latest save was played with a different mod list.

## Look and feel

- A charcoal theme with a blood-red accent, and a new logo.
- A frameless window with its own title-bar buttons.
- Blueprint-paper backgrounds behind shadowed cards, and masking-tape section labels.
- Links to the Discord, Ko-fi and GitHub.
